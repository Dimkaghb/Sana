## Execution record

- Milestone 1 passed locally with Python 3.12. The validator accepted 27 fixture files across seven scenarios and all 19 contract tests passed. Contracts B and C now represent unavailable identity and sensor evidence explicitly. The missing-sensor case exercises step-up. Waveform comparisons include the half-unit rounding boundary.
- Milestone 2 passed against a real local Uvicorn process with explicit mock ML. Run `python -m scripts.check_demo` from the backend environment. All seven scenarios produced matching schema-valid C and D. The check covers same-payload retry, conflicting reuse, authenticated case export, and dashboard recovery after restarting the process.
- Milestones 3 and 4 passed software checks for native pointer provenance, virtual motion, sensor denial, account changes, cleanup and targeted commands. A stationary virtual sensor stream produced a covered hold while absent motion led to step-up. Pixel-sized emulation and the system WebKit engine each completed a transfer. Real handheld and tabletop measurements are pending.
- Milestone 5 passed the production frontend build and browser tests for the mobile, dashboard and Guardian surfaces. The live dashboard recovers its snapshot, deduplicates scored sessions, distinguishes unavailable evidence, and preserves current ban state when displaying historical events.
- Milestone 6 passed with separate FastAPI and ML processes. Three independently attested synthetic sessions established a baseline. A subsequent match succeeded, a cross-account repeat triggered a hold, and a confirmed ban triggered a re-entry hold. A separate native Qdrant rehearsal verified search with an HNSW index. Run `python -m scripts.check_live` from the backend environment with the prepared ML environment and model.
- Milestone 7 has an [offline deck](../frontend/public/pitch.html) and a [60-second backup recording](demo/software-rehearsal.mp4). Fixtures exercised all seven cases and the software recovered decisions after restart. The actual four-person calibration and timed physical presentation are pending.
- Milestone 8 has a trained baseline and an optional temporal-attention encoder, with [held-out synthetic comparisons](../ml/README.md). Real-participant evaluation and threshold selection are pending. Recipient liveness is an explicit pass/fail simulation. Camera-based rPPG remains an optional research item.
- Milestone 9 passed the software flow from held session through account-scoped Guardian notification, acknowledgement, freeze, and case export. Actual second-phone notification delivery remains a device rehearsal item.
- Milestone 10 has a fresh local startup command, private per-run credentials, a single-origin HTTPS server, and a reset procedure that preserves earlier runs. The compiled app completed a TLS rehearsal with zero external browser requests. Physical trust installation, a venue-style LAN with the internet disconnected, and projector legibility at stage distance remain pending. See the [runbook](OFFLINE_REHEARSAL.md).
